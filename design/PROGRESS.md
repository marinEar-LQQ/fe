1. 카탈로그에 없는 **부두 설명(“신항 1부두”, 03 아래 “1부두 ─ 4부두” 줄)은 숨김**. 항만 줄은 카탈로그 `port` 값. 선석은 카탈로그 그대로(T1~T5).
2. 08 **잡음 완화·원음/완화음 비교 토글 → “항상 켜짐” 상태 표시** (엔진에 끄는 옵션이 없음).
3. 02 시안의 “+ 예시 교신 추가 / 시연 시작” → **수신 시작 / 파일 분석**, 시연 시나리오는 Mock 엔진일 때만.
4. **상단은 로고 + (엔진 모드·수신 상태) + 설정**만. 화면 제목은 본문 h1, 작업 기준은 02 의 현재 작업 기준 칸.
5. **다국어 범위**: 화면 문구 전부. 교신 원문(한국어)과 엔진이 보내는 문구(오류 원문, 정형 요약 라벨·지시어 표현)는 엔진 것 그대로.
6. **03/04 는 한 화면**(`/reviews/:id`)에서 판정에 따라 레이아웃이 바뀜.
7. 온라인 모드 기본, 첫 온라인 분석 전 동의(기억), ONLINE_UNAVAILABLE 자동 재시도 금지.

## 4. 남은 문제

1. **실제 클라우드 모델·중계 서버 미검증** — `design/VERIFY.md` 로 팀원 검증 필요.
2. 온라인 모드에서 엔진 `readiness.canAnalyze` 가 서버 확인 전에도 true — 프론트가 `/api/health` 결과로 막고 있음 (백엔드 요청 1).
3. ONLINE_UNAVAILABLE 로 실패한 발화는 원음만 남고 **다시 분석할 방법이 없음** (백엔드 요청 2).
4. 파일 분석 도중 취소 불가 (`analyzeFile` 에 취소 수단 없음).
5. Service Worker 새 버전 안내 없음 — 앱 탭을 모두 닫아야 적용.
6. 엔진이 보내는 오류 원문·TXT 내보내기는 한국어만 (화면에는 코드별 번역 라벨을 크게 보임).
7. id/vi 문구 원어민 검수 전 (`design/I18N_TODO.md`).
8. 교신 화면 목록은 새 수신·파일 분석을 시작하면 비우고 그 세션만 보임(새로고침 직후에는 작업 전체 복원). 작업 일지·재확인 목록은 항상 전체.
9. lint 경고(effect 안 setState) 몇 건 — 기존 패턴, 오류 아님.
